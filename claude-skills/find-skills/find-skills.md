# find-skills

설치 가능한 스킬 찾기/설치

## 설명
"이런 스킬 있어?", "X 하려면 어떻게 해?" 같은 질문에 설치 가능한 에이전트 스킬을 찾아서 설치해 준다.

## 언제 쓰나
- 필요한 기능이 스킬로 존재하는지 알아보고 싶을 때
- 새 스킬을 검색해서 설치하고 싶을 때

## 호출 방법
- Claude Code에서 `/find-skills` 으로 직접 호출하거나, 관련 요청을 하면 자동으로 선택된다
- 요청에 스킬 이름을 넣으면 확실히 호출된다

## 요청 예시
- `PDF 다루는 스킬 있어?`
- `find-skills로 테스트 자동화 스킬 찾아줘`
