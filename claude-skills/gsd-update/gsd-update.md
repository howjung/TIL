# gsd-update

GSD 최신 버전 업데이트 + 변경 내역 표시

- 분류 : GSD / 설정 / 유지보수
- 호출 : Claude Code에서 `/gsd-update` (GSD 설치기로 설치된 스킬)

## 사용법
```
/gsd-update [--sync | --reapply | --next | --rc]
```
- 대괄호 `[ ]` 는 생략 가능한 인자, `<>` 는 필수 값, `|` 는 택일이다
- 인자 없이 `/gsd-update` 만 입력해도 실행되며, 필요한 값은 Claude가 되묻는다

## 같은 분류의 스킬
- `gsd-config` : 워크플로 토글, 고급 옵션, 연동, 모델 프로필 설정
- `gsd-settings` : 워크플로 토글과 모델 프로필 설정
- `gsd-health` : planning 디렉터리 상태 진단 및 복구
- `gsd-surface` : 노출할 스킬 프로필 적용/목록/클러스터 끄기 (재설치 없이)
