# gsd-ns-context

코드베이스 정보: map, graphify, docs, learnings, mempalace

- 분류 : GSD / 네임스페이스 (묶음 진입점)
- 호출 : Claude Code에서 `/gsd-ns-context` (GSD 설치기로 설치된 스킬)

## 사용법
```
/gsd-ns-context
```
- 별도 인자가 없다. `/gsd-ns-context` 만 입력하면 된다

## 같은 분류의 스킬
- `gsd-ns-ideate` : 아이디어 포착: explore, sketch, spike, spec, capture
- `gsd-ns-manage` : 관리: config, workspace, workstreams, thread, update, ship, inbox
- `gsd-ns-project` : 프로젝트 수명주기: 마일스톤, 감사, 요약
- `gsd-ns-review` : 품질 관문: code review, debug, audit, security, eval, ui
- `gsd-ns-workflow` : 워크플로: discuss, plan, execute, verify, phase, progress
