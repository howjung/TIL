# agent-browser

웹 브라우저 자동화 CLI

## 설명
웹 브라우저 자동화 CLI. 페이지 이동, 폼 입력, 클릭, 스크린샷, 데이터 추출, 웹앱 테스트(QA), Electron 앱(Slack/Discord/VS Code 등) 자동화

## 언제 쓰나
- 웹사이트를 열어서 폼 작성, 로그인, 버튼 클릭 등을 자동화할 때
- 페이지 스크린샷을 찍거나 데이터를 긁어올 때
- 만든 웹앱을 직접 돌려 보며 QA/버그 헌팅을 할 때
- Slack 안 읽은 메시지 확인, 메시지 전송 등 Electron 앱을 자동화할 때

## 호출 방법
- Claude Code에서 `/agent-browser` 으로 직접 호출하거나, 관련 요청을 하면 자동으로 선택된다
- 요청에 스킬 이름을 넣으면 확실히 호출된다

## 요청 예시
- `agent-browser로 이 사이트 스크린샷 찍어줘`
- `이 웹앱 로그인부터 결제까지 테스트해 줘`
