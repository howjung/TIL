# gsd-capture

아이디어/할 일/메모/씨앗을 알맞은 곳에 저장

- 분류 : GSD / 아이디어 / 탐색
- 호출 : Claude Code에서 `/gsd-capture` (GSD 설치기로 설치된 스킬)

## 사용법
```
/gsd-capture [--note | --backlog | --seed | --list | --list-seeds] [text]
```
- 대괄호 `[ ]` 는 생략 가능한 인자, `<>` 는 필수 값, `|` 는 택일이다
- 인자 없이 `/gsd-capture` 만 입력해도 실행되며, 필요한 값은 Claude가 되묻는다

## 같은 분류의 스킬
- `gsd-explore` : 계획 확정 전 소크라테스식 아이디어 정리와 라우팅
- `gsd-sketch` : 버리는 HTML 목업으로 UI 아이디어 스케치
- `gsd-spike` : 직접 실험으로 아이디어 검증
- `gsd-extract-learnings` : 끝난 phase에서 결정/교훈/패턴/놀라운 점 추출
