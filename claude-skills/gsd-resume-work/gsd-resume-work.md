# gsd-resume-work

이전 세션 맥락을 복원해서 재개

- 분류 : GSD / 세션 이어가기 / 작업 공간
- 호출 : Claude Code에서 `/gsd-resume-work` (GSD 설치기로 설치된 스킬)

## 사용법
```
/gsd-resume-work
```
- 별도 인자가 없다. `/gsd-resume-work` 만 입력하면 된다

## 같은 분류의 스킬
- `gsd-pause-work` : 작업 중단 시 컨텍스트 인수인계 문서 작성
- `gsd-thread` : 세션을 넘나드는 지속 컨텍스트 스레드 관리
- `gsd-workspace` : 격리된 작업공간 생성/목록/삭제
- `gsd-workstreams` : 병렬 작업 흐름 목록/생성/전환/상태/완료/재개
