# design-taste-frontend

템플릿 티 나지 않는 프론트엔드 제작

## 설명
안티 슬롭 프론트엔드 스킬. 랜딩페이지, 포트폴리오, 리디자인에서 브리프를 읽고 알맞은 디자인 방향을 추론해 템플릿 같지 않은 인터페이스를 만든다. 리디자인은 점검부터 시작하고, 마지막에 체크리스트로 검수한다.

## 언제 쓰나
- 랜딩페이지나 포트폴리오를 새로 만들 때
- 기존 사이트를 리디자인할 때
- AI가 만든 듯한 뻔한 디자인을 피하고 싶을 때

## 호출 방법
- Claude Code에서 `/design-taste-frontend` 으로 직접 호출하거나, 관련 요청을 하면 자동으로 선택된다
- 요청에 스킬 이름을 넣으면 확실히 호출된다

## 요청 예시
- `design-taste-frontend로 카페 브랜드 랜딩페이지 만들어줘`
- `이 포트폴리오 사이트 리디자인해 줘`
