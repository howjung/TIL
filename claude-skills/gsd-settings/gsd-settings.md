# gsd-settings

워크플로 토글과 모델 프로필 설정

- 분류 : GSD / 설정 / 유지보수
- 호출 : Claude Code에서 `/gsd-settings` (GSD 설치기로 설치된 스킬)

## 사용법
```
/gsd-settings
```
- 별도 인자가 없다. `/gsd-settings` 만 입력하면 된다

## 같은 분류의 스킬
- `gsd-config` : 워크플로 토글, 고급 옵션, 연동, 모델 프로필 설정
- `gsd-health` : planning 디렉터리 상태 진단 및 복구
- `gsd-update` : GSD 최신 버전 업데이트 + 변경 내역 표시
- `gsd-surface` : 노출할 스킬 프로필 적용/목록/클러스터 끄기 (재설치 없이)
