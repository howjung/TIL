# 📚 자바 객체지향 프로그래밍(OOP) 핵심 정리 노트

## 1. 객체지향 프로그래밍(OOP)의 기본 개념
* **현실 세계의 객체(Object)**: 존재하거나 표현할 수 있는 모든 것 (속성과 기능 보유)
* **클래스(Class)**: 객체를 만들기 위한 **설계도(틀)** 이자 **사용자 정의 데이터 타입**
* **인스턴스(Instance)**: 클래스로부터 `new` 연산자를 통해 힙(Heap) 메모리에 생성된 실제 객체
* **클래스의 3대 구성 요소**:
  1. **필드 (Field)**: 객체의 데이터(속성)가 저장되는 공간
  2. **생성자 (Constructor)**: 객체 생성 시 초기화를 담당하는 특별한 블록
  3. **메소드 (Method)**: 객체의 동작(행위)에 해당하는 실행 코드 블록

---

## 2. 생성자(Constructor)와 `this` 키워드

### ① 생성자 (Constructor)
* `new` 연산자로 객체를 생성할 때 호출되어 객체의 필드를 초기화함.
* **특징**: 클래스 이름과 동일하며, 메소드와 달리 **반환 타입(void 등)이 없음**.
* **기본 생성자(Default Constructor)**: 클래스 내에 생성자가 작성되지 않은 경우 컴파일러가 자동으로 추가함.

### ② `this` 키워드
* `this`: 객체 자신을 가리키는 참조 변수. 인스턴스 변수(필드)와 매개변수의 이름이 동일할 때 구분하기 위해 사용함.
* `this()`: 동일한 클래스 내의 다른 생성자를 호출할 때 사용. 생성자 오버로딩 시 중복 코드를 줄여줌.

---

## 3. 오버로딩(Overloading) vs 오버라이딩(Overriding)

| 구분 | 오버로딩 (Overloading) | 오버라이딩 (Overriding) |
| :--- | :--- | :--- |
| **정의** | 같은 클래스 내에서 동일한 이름의 메소드/생성자를 여러 개 정의 | 부모 클래스로부터 물려받은 메소드를 자식 클래스에서 재정의 |
| **조건** | **매개변수의 개수 또는 타입**이 달라야 함 | 부모 메소드와 **시그니처(메소드명, 매개변수, 반환타입)** 가 완전히 동일해야 함 |
| **목적** | 다양한 입력 형태에 맞춰 동일한 이름의 기능 제공 | 자식 클래스에 맞게 부모의 기능을 변경/확장 |

---

## 4. 접근 제한자(Access Modifier)와 캡슐화
객체의 데이터를 외부의 잘못된 접근으로부터 보호(정보 은닉 및 캡슐화)하기 위해 접근 제한자를 사용합니다.

### ① 접근 제한자 종류
* `public`: 어디서나 접근 가능.
* `protected`: 같은 패키지 또는 상속받은 자식 클래스에서 접근 가능.
* `default` (생략 시): 같은 패키지 내에서만 접근 가능.
* `private`: **해당 클래스 내부에서만** 접근 가능 (상속받은 자식도 직접 접근 불가).

### ② Getter / Setter 메소드
* **`Getter` (`getXXX()`)**: `private` 필드의 값을 안전하게 가공하거나 읽어 전달할 때 사용.
* **`Setter` (`setXXX()`)**: 외부에서 전달받은 값을 검증/가공한 후 `private` 필드에 안전하게 저장할 때 사용.

---

## 5. 인스턴스 멤버 vs 클래스(정적) 멤버

### ① 인스턴스 멤버 (Instance Member)
* 객체(인스턴스)마다 개별적으로 존재하는 필드와 메소드.
* `new` 키워드로 객체를 생성한 후에만 접근 가능.

### ② 클래스 / 정적 멤버 (Static Member)
* `static` 키워드가 붙으며, 객체 생성 없이 `클래스명.멤버`로 접근 가능.
* 메모리의 정적 영역에 하나만 생성되어 모든 객체가 공유함.
* **주의**: 정적 메소드(`static method`) 내부에서는 인스턴스 필드/메소드 및 `this` 키워드를 사용할 수 없음.

---

## 6. 클래스 상속(Inheritance)과 `super`

### ① 상속 (Inheritance)
* 기존 부모 클래스의 필드와 메소드를 자식 클래스가 물려받아 사용.
* 문법: `class 자식클래스 extends 부모클래스`
* **장점**: 코드 재사용성을 높이고 유지보수를 용이하게 함.

### ② `super` 키워드
* **`super()`**: 자식 객체가 생성될 때 부모 객체의 생성자를 호출하는 역할. 자식 생성자의 **첫 줄**에 위치해야 함.
* **`super.메소드명()`**: 자식 클래스에서 오버라이딩되어 숨겨진 부모 클래스의 원본 메소드를 호출할 때 사용.
